# CMS Marketplace API fixtures

Sample responses in the CMS Marketplace API JSON shape
(https://developer.cms.gov/marketplace-api/). Used when
`transition.cms.mode=fixture` (local development) and by tests.

**All plan names, issuers, NPIs and prices are made up.** Premiums in
`plans-search.json` are for one 40-year-old; `FixtureCmsClient` scales them by age.
